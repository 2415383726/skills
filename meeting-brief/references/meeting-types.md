# 会议类型与准备重点

本地化自上游 meeting-briefing 的会议类型指引（原版面向法律团队，已去领域化）。认清会议类型，才知道该准备什么。

| 会议类型 | 准备重点 |
| --- | --- |
| 决策会（办公会、党委会、专题会） | 议题清单与每个议题的决策点；需上会材料的完备性（是否过征求意见、会签程序）；上次会决议的落实情况；表决/议定所需的数据和方案比选 |
| 专题协调会 | 各方当前进展与卡点；争议焦点与各方立场；上次协调会定的事项及未完成原因；本次要协调的具体问题（写清"请谁让什么步"）；可让与不可让的底线 |
| 汇报会/调度会 | 汇报内容的最新数据（截至日）；进度对标（计划 vs 实际）；问题与需上级支持事项；领导上次关注过的问题的回应；汇报时长与详略（5分钟版和完整版） |
| 外部会谈（企业、基层、上级调研） | 对方背景与历史交往；我方目标与底线；对方可能提出的要求与回应口径；政策依据与权限边界；承诺事项的管理（哪些能当场答应、哪些要带回来研究） |
| 全体会议/宣讲会 | 传达要点清单；与大家利益相关的变化（制度、流程）；答疑准备（高频问题）；通知与组织事项确认 |

## 通用准备清单（任何会议都过一遍）

- 议程拿到了吗？没有议程时向组织者确认议题和顺序；
- 上次同主题会议的纪要找到了吗？遗留行动项完成了没有；
- 我要讲的数字是最新的吗？截至日是什么时候；
- 需要谁会前对口径（避免会上两个部门数字打架）；
- 材料带齐了吗：纸质份数、电子版、演示设备。

## 准备缺口的处理（沿用上游纪律）

收集阶段找不到、无法核验的信息，一律进简报的"准备缺口"栏：

- 没找到的：上次会议纪要缺失、某文件没拿到——写明"未获取，建议向××索取"；
- 无法核验的：数据没有出处、转述的领导意见——写明"待核实，暂不写入发言要点"；
- 未回答的：议题的决策条件是否成熟——写成会前要问的问题。

缺口本身也是准备成果：知道缺什么，会前还来得及补。
