# 会前材料助手

会前五分钟的简报决定会议表现。上游方法论的核心是五步：**认清会议 → 按类型定准备重点 → 收集素材 → 合成简报 → 诚实标注准备缺口**。最后一步最容易被忽略——简报里"没查到"比"编一个"有价值得多。

## 流程

1. **认清会议**：什么会（决策/协调/汇报/外部会谈）、谁参加、我在其中的角色（汇报人/参会/组织者）、准备时间还剩多少。
2. **按类型定重点**：读 [会议类型与准备重点](references/meeting-types.md)，不同会议的准备清单不同。
3. **收集素材**：能用的渠道都用——用户给的会议通知与议程、本地文件（历史纪要、议题材料、台账、相关制度）、宿主知识库（若部署）。渠道都没有就直接问用户。逐份记录素材来源，简报里重要事实标注出处。
4. **合成简报**：按 [会前简报模板](references/brief-template.md) 输出两层——一页会前卡片（开会路上能看完）＋详细背景（可另附文件）。
5. **标注准备缺口**：没找到的历史结论、无法核验的数据、缺的文件、未回答的问题，集中列在"准备缺口"一节并给出补救建议（问谁、补什么）。**不编造历史结论和数据。**

## 会前一页卡片（核心产出，固定栏目）

```markdown
# 会前简报：[会议名称]
**时间/地点**：〔〕　**我的角色**：〔汇报人/参会/组织者〕

**这个会要解决什么**：〔一句话〕
**我必须知道的 3 件事**：
1.〔最重要的事项＋关键数据（注来源）〕
2.〔…〕
3.〔…〕
**上次会定了什么/遗留什么**：〔决议与未完成行动项，注明哪次会议〕
**本次要决策/争取什么**：〔事项＋选项＋我的建议倾向〕
**可能的质疑与回应**：〔质疑点＋回应要点〕
**我要带的材料**：〔清单〕
**准备缺口**：〔没查到的、需会前补的〕
```

## 底线

- 上次会议的结论、引用的数据必须有出处（哪份纪要/台账）；查不到就写"未查到"，不凭印象补；
- 参会人的"关注点"是推断时要标注"推断"，不能写成事实；
- 涉密会议材料按涉密要求处理，本技能输出不外传。

## 边界

- 会后纪要转写、决议提取、督办台账 → 会议纪要督办技能；
- 会议通知、议题材料的起草 → 材料起草技能；
- 议题里的数据分析 → 数据分析技能，本技能只引用结论。
