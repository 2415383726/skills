# meeting-brief（会前材料助手）

会前五分钟简报：会议目的、参会人关注点、上次结论、待决策事项、发言要点、材料清单，查不到的如实标注准备缺口。本地化自 anthropics/knowledge-work-plugins 的 meeting-briefing（去法律领域化）。

## 上游来源与修改说明

- 上游：anthropics/knowledge-work-plugins · legal/meeting-briefing（Apache-2.0）。
- 保留：五步法（识别会议→按类型评估准备需求→从可用渠道收集→合成简报→标注准备缺口）、Briefing Template 骨架、"渠道缺失就直接问用户"的降级路径。
- 修改（本地化）：法律领域限定（CLM/CRM/监管会议/privilege）去除，替换为决策会、专题协调会、汇报调度会、外部会谈、全体会议五类机关会议（docx S10）；日历/邮件/Slack 渠道替换为本地文件、会议纪要、宿主知识库；新增"一页会前卡片"核心产出层；行动项跟踪部分拆分至 meeting-minutes 技能（S11）。

将整个 `meeting-brief` 文件夹放入宿主 skills 目录，刷新技能列表。
