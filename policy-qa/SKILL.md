# 制度政策问答

回答制度类问题的生命线是**依据可追溯**：答案可以短，出处不能少。组织人事场景里，一个没有出处的"应该可以"可能让人办错事。

## 作答流程

1. **弄清问题**：用大白话确认用户问的是什么，具体到人群和情形——"年休假"和"异地借调人员的年休假"答案可能不同。用户问得笼统时按最常见情形作答并说明前提。
2. **找依据**（按可用渠道依次尝试）：
   - 用户给了制度库文件夹路径：运行检索脚本（支持 txt/md/docx）：
     ```bash
     python "<SKILL>/scripts/search.py" "<制度库目录>" "年休假" "带薪年休假"
     ```
     多给几个同义关键词（如"报销""差旅费"），命中按文件汇总。
   - 用户粘贴了制度文本：直接在文本中定位相关条款。
   - 宿主部署了知识库检索能力：按其方式检索，引用时注明检索位置。
   - 都没有：请用户提供相关制度文件；用户无法提供时按下述护栏拒答。
3. **按格式作答**：见 [答案格式规范](references/answer-format.md)。快速结论在前，依据随后，细节和例外用大白话解释。
4. **版本与时效检查**：检索命中多份文件时，比对发文时间与废止标记；新旧规定冲突时，以新版为准并明确提示"《A》已被《B》修订/替代，请勿按旧文办理"。

## 护栏（不可违反）

- **必须引用出处**：每条实质性答案给出文件名＋文号（如有）＋条款/章节；出处缺失的答案就是不合格的答案。
- **检索不到就明说**：回答"未检索到明确规定，建议咨询××部门确认"，绝不基于常识猜一个"应该可以/不可以"。
- **区分"规定如此"与"我的理解"**：解释性内容（条文没说清的地方）明确标注"个人理解，建议以主管部门解释为准"。
- **敏感事项升级**：涉及干部选拔任用、纪律处分、薪酬保密的具体个案，提示走正式咨询渠道，答案只给一般性制度规定。

## 边界

- 制度修订对比 → 制度对比技能；
- 新起草或修订制度文本 → 材料起草技能；
- 具体个案的合规判断、劳动争议 → 建议咨询组织人事部门或法务，本技能不做个案裁定。
