# policy-qa（制度政策问答）

回答制度类问题并强制带出处：结论＋条款引用＋例外＋咨询渠道。检索不到明确规定就明说，不猜。本地化自 anthropics/knowledge-work-plugins 的 policy-lookup。

## 上游来源与修改说明

- 上游：anthropics/knowledge-work-plugins · human-resources/policy-lookup（Apache-2.0）。
- 保留：五步作答流程（检索→白话作答→引用条文→说明例外→指明咨询人）、三道护栏（必引出处、找不到明说、合规问题建议问部门）、答案输出骨架。
- 修改（本地化）：PTO/401k/远程办公等国外福利主题替换为休假、差旅报销、考核、编制等机关制度主题；"知识库/HRIS 连接器"双模式本地化为"制度库文件夹检索 / 粘贴文本 / 宿主知识库"三渠道；输出字段本地化（文件名＋文号＋条款＋生效日期＋适用范围）；新增版本冲突拦截与敏感个案升级护栏（docx S04 要求）。
- 新增脚本：scripts/search.py——上游"知识库自动检索"的内网等价实现（目录遍历＋关键词定位＋docx 标准库解析），只做定位不做语义判断。

## 安装与使用

将整个 `policy-qa` 文件夹放入宿主 skills 目录，刷新技能列表。制度库建议集中为一个文件夹（txt/md/docx）；无制度库时用户粘贴制度文本同样可用。

运行机械回归：

```bash
python -m unittest discover -s policy-qa/tests -v
```
