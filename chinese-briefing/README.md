## 上游来源与修改说明

- 上游：anthropics/skills · internal-comms（SKILL.md ＋ examples/ 四份指南，Apache-2.0）。
- 保留：四类沟通的分治结构、"先问清场合再动笔"、严格格式纪律（3P 三节、Newsletter 取舍原则、FAQ 基于官方口径作答）、"没有渠道就问用户要素材"的降级路径。
- 修改（本地化）：Slack/Google Drive/Email/Calendar 等工具引用替换为内网等价物（本地文件、会议纪要、OA 素材、宿主知识库）；3P 格式的 emoji 抬头改为机关惯用的部门名＋日期区间；Newsletter 的公司语境改为单位语境、"we"改为"我单位"；新增"数据与事实"约束（【数据待补】、责任人待确认）与"领导更新信息顺序"内网补充；FAQ 补充制度文件场景的作答规则。
- 未修改上游的许可与署名要求；Apache-2.0 许可证全文随目录携带。

## 安装与使用

将整个 `chinese-briefing` 文件夹放入宿主 skills 目录，刷新技能列表。用户说"写周报/月报/简报/动态/FAQ"即触发；起草哪类只读哪份指南。

## 与流水线的衔接

对外正式公文走 chinese-drafting；定稿前错字标点交 chinese-proofread；成稿内容审读交 chinese-review；数据结论来自数据分析类技能。
