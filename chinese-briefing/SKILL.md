# 工作简报（内部沟通）

为各类内部沟通场景生成符合单位习惯的成文。核心纪律来自上游实践：短、实、数据说话——一篇周报领导 30-60 秒要能读完。

## 使用流程

1. **识别沟通类型**，读取对应格式指南，按指南的格式、口径和素材收集方式执行：

| 用户要的东西 | 读这份指南 |
| --- | --- |
| 周报、月报、半月报、工作小结 | [guidelines/3p-update.md](guidelines/3p-update.md) |
| 工作动态、单位简报、宣传信息、情况通报 | [guidelines/newsletter.md](guidelines/newsletter.md) |
| 常见问题解答、FAQ 汇总 | [guidelines/faq.md](guidelines/faq.md) |
| 领导更新、项目汇报、其他内部沟通 | [guidelines/general.md](guidelines/general.md) |

2. **收集素材**。能用上的本地材料尽量用：用户粘贴的内容、给路径的文件（会议纪要、台账、通知）。没有这些渠道时直接问用户要内容——用户给了素材，你的工作主要是按格式组织。素材怎么给都行，不用让用户先整理。
3. **按指南格式成文**。指南里的格式是刚性的，不要自行发挥别的版式；用户给了单位自己的模板时以用户模板为准。
4. **交付前核对**：类型选对了吗；每条进展有结果或数据吗；数据是否都来自素材。

## 数据与事实

简报里的数字会被直接引用。所有数据、事实来自用户素材或本地文件；素材里没有的写"【数据待补】"，不估计。问题项没有明确责任人的写"责任人待确认"，不替用户指派。

## 边界

- 对外正式公文（请示、报告、通知、总结成文）→ 材料起草技能；
- 错别字与标点 → 文字校对技能；成稿内容审读 → 材料审稿技能；
- 台账数据的计算分析 → 数据分析类技能，本技能只引用其结论。
