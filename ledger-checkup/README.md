# ledger-checkup（台账数据体检）

导入/上报前对人员台账做字段级体检：身份证校验与交叉一致性、唯一键、必填、日期逻辑、枚举漂移，输出红黄错误行清单和修复建议。本地化自 anthropics/knowledge-work-plugins 的 explore-data。

## 上游来源与修改说明

- 上游：anthropics/knowledge-work-plugins · data/explore-data（Apache-2.0）。

- 修改（本地化）：数据仓库画像替换为人员台账体检——新增身份证校验码（GB 11643）与出生/性别/年龄交叉校验、唯一键查重、必填缺失、日期格式混用、枚举漂移（空格/全角差异）、低基数完整性分级；敏感字段打码与只读红线按内网治理要求新增；清洗副本改为显式 opt-in。

## 安装与使用

将整个 `ledger-checkup` 文件夹放入宿主 skills 目录，刷新技能列表。运行机械回归：

```bash
python -m unittest discover -s ledger-checkup/tests -v
```
