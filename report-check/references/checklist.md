# 交付前复核清单

脚本管"算得对"，本清单管"算得该不该"。来自上游 validate-data 的交付前 QA 清单，按机关报表语境改造。逐项过，发现项并入红黄绿清单。

## 口径与定义

- [ ] 每个指标的定义在表内或附注中说得清（"在编人员""办件量"按哪个口径）；
- [ ] 同一指标在多张表/多个段落中口径一致（在编 vs 实有、累计 vs 当期）；
- [ ] 分母明确且非零：率＝分子/分母，分母是什么、有没有变化。

## 时间与基期

- [ ] 同比环比的基期正确："较去年"是比去年同期还是去年全年；
- [ ] 比较期间长度一致：不拿半个月和整月比、不拿没结束的月份说下降；
- [ ] 报表截止日统一：多张表的"截至"日期一致。

## 一致性与勾稽

- [ ] 表内勾稽：分项之和＝合计（脚本已查）、期初＋本期增加－本期减少＝期末；
- [ ] 跨表勾稽：报表数 vs 底表数、正文引用数 vs 表内数；
- [ ] 与历史报表衔接：上期结转数对得上；对不上的列出来源差异。

## 计算方法

- [ ] 平均数是加权的（人均≠各组人均的平均）；
- [ ] 百分比口径统一（小数制 vs 百分数不混排）；
- [ ] 增长表述自洽：增幅、差值、基期三者关系成立。

## 展示（报送版）

- [ ] 图表不歪曲：柱状图零起点、双轴刻度不误导、标题说的是图里的事；
- [ ] 数字精度一致：全表小数位统一，千分位统一；
- [ ] 表内单位标注清楚（元/万元），换算处已复核。
