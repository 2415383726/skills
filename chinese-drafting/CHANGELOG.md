# 变更记录

## v1.0（2026-09-13）

初版。对应《内网 AI Agent Skill 资产建设清单与二开建议 V1.0》S01。

- SKILL.md：三阶段流程（收集素材 → 按类型定结构逐段起草 → 自查扫描交付）、唯一硬约束（事实可溯源、【待补】占位、不编造）、快速/结构化两种模式。
- 吸收 doc-coauthoring 上线验证的协作模式（经人工复审后择优引入）：素材倾倒式收集与"细节级提问即开工"的上下文充分性判据；重要材料骨架确认门；主体先行的起草顺序（总述最后写）；观点性内容 3-5 候选共创；外科手术式修改与用户偏好学习；收尾通读查衔接、重复、矛盾与删减提醒；用户通读确认与责任边界。
- references：共同写作规则（语体、时间、数字、套话控制、提问方式）、待补事实规范（占位符格式、待补清单、定稿条件）、读者测试（自查＋子代理两级）。
- references/types：9 类材料规则（工作总结、工作计划、情况汇报、请示、通知、会议材料、述职材料、经验交流材料、讲话稿/提纲），每类含结构骨架、常用表达、禁忌、篇幅、事实核验点。
- assets/templates：9 类骨架模板，槽位统一【待补】标记，扫描即完成度清单。
- scripts/facts.py：骨架生成（new）、占位符扫描与待补清单（scan）、定稿检查（check）；Python 3.8+ 标准库，UTF-8/GBK 兼容。
- tests：20 项机械回归；evals：3 个起步用例。
