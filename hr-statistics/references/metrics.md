# 人员统计口径与报告边界

上游 people-report 的指标是跨国公司口径（attrition、diversity、eNPS），机关人事用不上也不该照搬。本文件定义本技能使用的单位口径，所有报告的"口径与方法"节必须与这里一致；单位另有规定时以单位规定为准并替换本文件。

## 核心口径

| 指标 | 口径 | 说明 |
| --- | --- | --- |
| 在册人数 | 台账中状态为在编/在岗的记录数 | 明确是否含借调、返聘、试用期 |
| 编制 vs 实有 | 编制数来自编制文件；实有数来自台账 | 两者差＝空编/超编，分科室列 |
| 学历结构 | 按最高全日制学历或最高学历（须注明） | 两种口径差异大，不可混用 |
| 年龄 | 截至基准日（默认统计日）的周岁 | 基准日必须写进报告 |
| 平均年龄 | 全体周岁年龄的算术平均 | 分科室平均须另算，不得由分组平均再平均 |
| 入职年限 | 周年数，截至基准日 | 区分本单位工龄与连续工龄 |
| 管理幅度 | 部门负责人直接分管人数 | 以台账"直属领导"字段为准 |
| 退休预测 | 按出生日期＋法定年龄推算到龄年份 | 脚本默认男60/女55，须注明不含延退/提前退政策 |

## 报告模板（本地化自上游 Output）

```markdown
## 人员结构报告：[类型] — [基准日]

### 领导摘要
[2-3 条关键结论，每条带数字]

### 关键指标
| 指标 | 本期 | 上期 | 趋势 |
| --- | --- | --- | --- |

### 分项分析
[部门/学历/年龄/职称等分项表＋一段解读；数据附所用命令，可复现]

### 异常与提示
[超编空编、年龄断层、即将到龄集中科室等]

### 口径与方法
[台账范围、基准日、所用脚本命令、数据质量说明]
```

## 边界（硬规则）

1. **只做事实汇总，不做人事判断**：不输出人员优劣排名、不产生任免/调岗/淘汰建议；"人手紧张"等判断交由领导结合业务量做出，报告只给编制实有差、人均业务量等客观参照。
2. **脱敏**：报告只出现汇总数；个人明细（姓名、身份证、工资）不进报告，临时排查除外且不落盘。
3. **敏感字段权限**：薪酬、考核结果等字段不在默认统计范围；用户明确要求且有权查看时才使用。
4. **可复现**：每个数字能说出所用命令与基准日；两次报告口径不同必须在"口径与方法"中声明。
