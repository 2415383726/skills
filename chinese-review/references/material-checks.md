# 材料一致性检查清单

逐项过，每项发现问题记入清单（定位＋理由）。来自上游交付前 QA 清单的公文版改造，检查的是"材料自己跟自己、材料跟依据是否一致"。

## 题文与结构

- [ ] 标题与正文说的是同一件事（题文一致）；副标题、时间段与正文范围一致。
- [ ] 文种用对：总结、报告、请示、通知各有结构要求；请示是否一文一事、有无规范结语。
- [ ] 开头交代了依据和目的；结尾与文种匹配（特此报告/妥否，请批示/特此通知）。
- [ ] 结构缺项：总结缺问题与下一步、计划缺责任人和时限、汇报缺基本情况——对照文种常规结构。

## 数字一致

- [ ] 同一数据在文中出现多次时数值、单位、口径完全一致（开头总数 vs 分项之和）。
- [ ] 分项加总等于合计；百分比加总约等于 100%（结构占比类）。
- [ ] 百分比能从分子分母反推：完成 23 件、完成率 92%，则总数应为 25 件，对不上就是问题。
- [ ] 同比环比的基期正确："较去年"是比去年同期还是去年全年；增幅与差值的关系自洽。
- [ ] 量级合理：人数、金额没有多零少零；负数出现在不该出现的地方（人数、完成率）。

## 时间逻辑

- [ ] 时间线自洽：事件的先后顺序不矛盾（验收在开工前就是错）。
- [ ] 总结范围与数据期间一致：标题写上半年，数据没有混入下半年。
- [ ] 截止时点一致：不同段落"截至"的日期不同却比较数据，属时段不可比。
- [ ] 计划类：各阶段起止衔接，无重叠无断档；时限晚于上级要求的截止日期。

## 主体与称谓

- [ ] 单位、部门名称全文一致（全称/简称统一，首次出现注明）。
- [ ] 人名、职务正确且前后一致（同一人两个职务、两个名字都是问题）。
- [ ] 责任主体与职权匹配：把事项派给没有该职权的部门要提示。
- [ ] 主送对象正确唯一（请示多头主送、越级主送是程序问题）。

## 政策与依据

- [ ] 引用的文件名称、文号、条款在材料内部前后一致。
- [ ] 引用与结论匹配：引 A 文件支持 B 结论是常见错误。
- [ ] 上级要求的关键点（时限、标准、报送要求）在材料中有回应，无遗漏。
- [ ] 无法核验文号真伪时明确注明"文号真伪未核"，不替材料背书。

## 措施与问题、目标与指标的对应

- [ ] 问题部分每个毛病，在措施/下一步有对应动作；措施有凭据地针对问题。
- [ ] 工作目标与考核指标匹配：目标值不高于也不低于下达的指标。
- [ ] "成效明显"类判断句后跟了数据或事例；没有支撑的判断标为建议级。

## 附件与引用

- [ ] 正文提到的附件在附件清单中存在，序号、名称一致；反之亦然。
- [ ] 报表、表格中的合计与正文引用的数字一致（跨表不一致是高发问题）。
- [ ] 图表标题说的是图里的事；数据期间与正文一致。
