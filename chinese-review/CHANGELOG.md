# 变更记录

## v1.0（2026-09-13）

初版。对应《内网 AI Agent Skill 资产建设清单与二开建议 V1.0》S03。组合本地化自 validate-data（Apache-2.0）与 doc-coauthoring。

- SKILL.md：七步审稿流程、三级判级（严重/一般/建议）、底线（定位＋理由、允许零问题、声明审查边界）、与校对/起草技能的边界。
- references：材料一致性检查清单（题文/数字/时间/主体/依据/对应/附件）、常见内容陷阱（口径漂移、时段不可比、平均的平均、幸存者偏差等，本地化自上游陷阱目录）、读者视角检查（领导三问＋假设/歧义/空话，源自 doc-coauthoring 读者测试）、问题清单与三档总评格式（源自 validate-data Validation Report）。
- evals：3 个起步用例（数字矛盾验算、请示程序文种、套话材料）。
