# Excel/台账数据分析

回答数据问题的可靠流程是六步，来自上游实践：**理解问题 → 确定口径 → 取数计算 → 交付前校验 → 呈现结论 → 视需要补图**。只做画图不算分析；没有校验的数字不要交付。

## 流程

1. **理解问题并分级**：
   - 快速查数：单个指标、简单筛选（"3 月报销了多少"）；
   - 完整分析：多维拆解、趋势、对比（"哪个部门人均培训费用最高"）；
   - 正式报告：给领导的分析材料。
   问题含糊时先确认：问的是哪个口径、哪个时间段、哪个人群。
2. **取数**：
   - 先 `preview` 看表结构，`profile` 看列类型——**中文字段名、标题行、合并表头**都要先认清再算：
     ```bash
     python "<SKILL>/scripts/table.py" preview 台账.xlsx --rows 5
     python "<SKILL>/scripts/table.py" profile 台账.xlsx --header 1
     ```
   - 表头不在第一行时用 `--header 行号`；多工作表用 `--sheet 名称`。
3. **计算**：用 `groupby` 做分组聚合，复杂计算拆成多步、每步可复核：
   ```bash
   python "<SKILL>/scripts/table.py" groupby 台账.xlsx --by 科室 --agg count --agg sum:金额 --header 1
   ```
   口径要点：百分比统一换算；金额单位（元/万元）先确认；"人数"类字段不得出现小数与负数；日期列统一格式后再比较。
4. **交付前校验**（五项，源自上游）：行数对不对（合计行是否被重复计入）、空值是否影响结果、数量级是否合理、时间序列有无断档、分项之和是否等于合计。校验不过就查明原因并注明，不带病交付。
5. **呈现结论**：按问题分级——快速查数直接给答案＋所用命令；完整分析先给关键发现再给数据表；正式报告给摘要＋方法与口径＋发现＋数据质量说明。**计算过程（所用命令和中间结果）必须保留**，让第二个人能算出同样的数。
6. **图表**：内网无图表库时不硬造图，给分组表＋文字解读；宿主有可视化能力时先确认图表不歪曲数值（柱状图零起点、坐标一致）。

## 底线

- 结论必须由数据支撑，材料里算不出的就说明缺什么；
- 异常发现（跳变、离群、逻辑矛盾）单独列出，注明判定标准；
- 原文件只读不改，输出写新文件或聊天内给出。

## 边界

- 交付前的报表纠错（查错数）→ 报表复核技能；导入前质量体检 → 台账体检技能；
- 人员结构等固定口径的定期报告 → 人力资源统计技能；
- 数据涉及个人敏感信息时，输出只给汇总数，不展开个人明细行。
