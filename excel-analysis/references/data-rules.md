# 内网数据口径与处理规则

上游 analyze 面向数据仓库，本技能面向单位里手工维护的 Excel/CSV 台账。这类表最常见的问题不是算错，是口径没说清。本文件固化内网数据处理的默认规则。

## 表结构识别

- 标题行：机关表格常在第一行放表名（"2025年度培训台账"），数据表头在第 2 行——用 `--header 1`；
- 合并表头：两级表头（"基本情况-姓名"）在 csv 里通常是"基本情况姓名"式拼接列名，profile 时确认含义；
- 合计行：底部的"合计/总计"行必须从计算中剔除，否则求和翻倍；
- 多工作表：先问清用哪张（"明细"、"汇总"常并存），默认第一张并向用户确认。

## 字段与数值规范

- 数值：千分位（1,234）、百分比（23.5%）自动识别换算；含单位的（"3.5万元"）先剥离单位并全文统一；
- 日期：xlsx 序列号转标准日期；文本日期（2025.3.1、2025/3/1、3月1日）统一为 2025-03-01 再比较；
- 人数类字段：出现小数或负数即为异常，先查数据再算；
- 空值：区分"没填"与"本就没有"；涉及比例计算时空值计入分母还是剔除，必须先问口径。

## 常用口径确认话术

分析前用一句话跟用户对齐口径，避免返工：

```text
确认一下口径：①"培训人次"是按参训场次累加还是按人头去重？
②金额单位是元还是万元？③统计截止到哪天？
```

## 组织层级汇总

- 部门名称不规范（"办公室"与"委办公室"混用）时，先做名称映射再汇总，映射关系让用户确认；
- 汇总层级（科室→部门→单位）逐级算，上级=下级之和；对不上时先查重复记录和交叉归属（一人多岗）。

## 异常发现的标准写法

每条异常三要素：数值＋判定标准＋建议动作。

```text
异常：财务科 3 月报销金额 89.7 万元，为 1-2 月月均（12.3 万元）的 7.3 倍。
标准：超过月均 3 倍列为异常跳变。
建议：核实是否存在年度集中报销或补录。
```
