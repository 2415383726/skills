# policy-diff（制度新旧对比）

对比新旧两版制度文件，输出条款级变化清单、影响对象和执行注意事项，用于制度宣贯与执行交底。按 docx 规划自研实现（上游仅借鉴工作流思想）。

## 设计说明

- **分工**：脚本只做确定性的条款拆分（支持中文条号"第十二条"、阿拉伯条号）、正文对齐（same/modified/added/deleted/renumbered）和文本比较；口径变化、含义变化、影响解读等语义判断由 Agent 基于对照表完成。
- **两个高危误判有专门对策**：文字没变但含义变（unchanged 条款引用外部文件的排查清单）、文字变了但意思没变（表述性差异不升级为实质修改）。
- 上游：docx 注明"建议自研实现；仅借鉴 employee-handbook＋文档对比模式的工作流"，本包未复制任何上游文本。
