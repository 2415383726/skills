# 对比报告格式

报告用于制度宣贯和执行交底，固定五部分。

```markdown
# 《××办法》修订对比报告

**旧版**：《××办法（试行）》（文号，发布日期）〔来源：用户提供/制度库〕
**新版**：《××办法》（文号，发布日期）〔来源：……〕
**说明**：以正式发布文本为准；本报告基于上述两版文件。

## 一、变化总览

| 变化类型 | 数量 | 条款 |
| --- | --- | --- |
| 实质修改 | 3 | 第五条（报销标准）、第八条（审批权限）、第十二条（时限） |
| 口径变化 | 1 | 第二条（适用范围） |
| 流程变化 | 1 | 第九条 |
| 新增 | 2 | 第十五条、第十六条 |
| 删除 | 1 | 原第十三条 |
| 文字性修改/编号调整 | 5 | （列出条号） |

## 二、逐条差异与判类

**第五条｜实质修改**：报销限额由 800 元提高至 1000 元。
**第八条｜责任变化**：审批主体由综合科变更为财务科。
**第十二条｜时限变化**：报送时限由 5 个工作日缩短为 3 个工作日。
（每条：条号 → 类型 → 一句话变化点；待确认的注明原因）

## 三、影响对象

**必须同步修改**
- 差旅报销单（金额上限字段）——牵连第五条
- OA 审批流（财务科节点）——牵连第八条

**建议同步更新**
- 办事指南第 3 节、FAQ 第 7 条——牵连第九条

## 四、执行注意事项

- ××月××日前按新标准受理，此前已受理的按旧标准办结（依新版附则第十七条）；
- 原《××办法（试行）》自新版施行之日起废止。

## 五、待确认

- 第九条新增"分管领导审批"环节，审批顺序未写明，需与牵头科室确认。
```

## 写作规则

- 总览表的数量与逐条明细条数必须一致；
- 每条差异给条号定位，宣贯时能直接翻到原文；
- 引用两版原文时精确摘录，不混写；
- "执行注意事项"只写能从文本推出或用户确认过的内容，推断处标注依据；
- 允许"零变化"结论：两版文字完全相同时如实说明，不硬找差异。
