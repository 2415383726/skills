# 影响检查清单

制度文本改了，围着它转的东西不会自己改。逐项排查并输出"需同步修改清单"，每项注明牵连的条款号。

## 排查维度

| 维度 | 排查点 |
| --- | --- |
| 配套表单 | 修订涉及的申请表、审批单、登记表：字段、勾选项是否还匹配 |
| 办事流程 | 流程图、办事指南中的环节、顺序、材料清单 |
| FAQ/办事问答 | 已发布的问答里按旧标准回答的内容 |
| 信息系统 | OA/业务系统中固化的审批流、字段枚举、校验规则（如金额上限） |
| 台账与报表 | 台账栏目、统计口径是否与新定义一致 |
| 下位制度 | 科室实施细则、操作规程中引用旧条款号或旧标准的地方 |
| 合同与模板 | 常用合同、协议模板中引用本办法条款的部分 |
| 宣贯材料 | 培训课件、海报、通知中写死的旧数字 |

## 影响对象识别方法

1. 从"实质修改/口径变化/流程变化/责任变化/时限变化"的条款提取关键词（金额、部门名、时限、表单名）；
2. 对每个关键词问：单位里哪些地方固化了这个关键词；
3. 用户提供了配套文件时逐一核对；没提供时按清单列"疑似受影响项"并注明依据（哪条变化、为什么牵连）。

## 输出要求

- 每项写清：受影响对象 → 牵连条款 → 需要改成什么（能确定时）或"需核对"；
- 分两档：必须同步修改（不改会办错事）与建议同步更新（不改会造成口径混乱）；
- 拿不准的列入"待确认"，不要为凑数把所有维度都写满。
