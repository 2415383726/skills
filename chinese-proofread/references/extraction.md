# 文件提取与宿主回退

## 依赖和环境

面向 Python 3.8+。Windows 7 使用 Python 3.8；麒麟 V10 x86-64 使用可用的 Python 3.8+。这些目标环境尚未实机验证，不依赖新版 Python 特性。

技能不附带第三方库、不自动安装、不联网。TXT、TEXT、MD、Markdown、DOCX 有直接标准库实现；XLSX、PPTX 先尝试环境中已有的 openpyxl / python-pptx，再用标准库基础提取。不会为它们强制安装编译型依赖。旧 XLS 需要 xlrd，依赖声明见 requirements-extraction.txt。运行时不检查精确版本，已有库直接尝试使用；安装时选择与当前 Python 和操作系统兼容的内网版本，不强制升级或降级。开发验证使用了 xlrd 2.0.2、openpyxl 3.1.5，这些是验证记录，不是强制版本，也不代表其他版本都已验证。et-xmlfile 等传递依赖交给包管理器处理，不在脚本中重复维护。

可用库也是有限范围提取，不等于还原整个办公软件。每次记录 extraction_backend 和 extraction_attempts，失败信息留在数据中供维护，不需要主 Agent 分析堆栈。

## 文件范围

| 文件 | 处理范围 |
| --- | --- |
| .txt / .text / .md / .markdown | 保留非空原始行、空格、换行分片和 Markdown 语法；不渲染、不总结 |
| .docx | 现有正文、表格、文字级修订视图；详细边界见 docx-extraction.md |
| .xlsx | 全部单元格工作表，含隐藏内容，保留坐标和首个非空行同列语境；公式只取已存缓存，不计算；不还原格式化数字/日期 |
| .pptx | 按实际幻灯片顺序提取显式文本、组合形状、表格和备注；页内为对象顺序，不模拟视觉布局；母版/版式继承文字、图片文字等不保证覆盖 |
| .xls | xlrd 读取单元格已存值，含隐藏工作表；不计算公式、不提取绘图文字 |
| .doc / .ppt / WPS 原生格式 | 无内置复杂二进制解析器，明确转交宿主现成读取工具 |

WPS 保存的标准 OOXML 内容按实际包类型识别，不只看扩展名。把标准 DOCX 改名成 .wps 可识别，不表示所有 .wps 都受支持。二进制 .et 可尝试 xlrd，只有实际通过验证才算成功；其他情况仍交给宿主。

文本自动识别 UTF-8/BOM 和带 BOM 的 UTF-16/UTF-32。已知其他编码时指定 --encoding gb18030 等实际编码；不盲猜编码把乱码当原文。Markdown 语法不删除，交给校对规则区分叙述和技术内容。

## 有界回退

正常调用：

```text
python "<SKILL>/scripts/extract_file.py" --input "<SOURCE>" --output "<WORK>/document.json"
```

ready 才表示完成。install_dependency 返回准确包名、当前解释器、retry_command 和 fallback_command。主 Agent 只从批准的内网包源或离线包安装，不为可选提取访问公网；安装后同一依赖最多再试一次。无法安装就走 fallback_command。

host_extract 返回一句完整 instruction、宿主输出路径和 resume_command。脚本在宿主读取前保存源文件快照，输出路径每次唯一，不误用上次的提取文本。默认宿主工具将完整 UTF-8 原文写入指定 .host-*.txt；不要总结、校对或凭记忆重建。

宿主结果写完后执行返回的 resume_command。可追加 --scope "正文、表格和文本框" 这样的实际范围；缺少说明时保留范围未知。对于宿主返回的标准 document.json，可追加 --host-document "实际路径"，结构见 data-format.md，保留准确段落/单元格/幻灯片位置。

恢复会重新核对源文件版本，再校验和绑定提取内容，最终输出与内置提取完全相同的 document.json 契约。源文件变了、结果未落盘、结果为空或结构错误时返回 blocked，不能带着旧结果进入校对。快照只证明版本关联，不证明宿主读全了内容。

--host-fallback 可直接跳过内置提取，产生相同的宿主接手请求。宿主也失败时结束该文件的提取并说明原因，不递归发起新一轮回退。

## 工程边界

输出不能覆盖源文件或写入技能目录。文件上限 128 MiB、XML 总量 64 MiB、包部件 10000、Excel 已存单元格上限 200000；超限转宿主，不静默截断为成功。XML 禁止 DTD/实体声明，不读取外部关系、不执行宏或公式。原文件、提取结果及范围分别保留，交付只使用通过验证的数据。

这些是解析器的有限范围约束，不是通用文档沙箱。无 OCR、外部模型调用、办公软件安装或复杂转换服务。
