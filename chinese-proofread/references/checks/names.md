# 名称一致性判据

N-CONSISTENCY 只用于文内可能指向同一对象的名称差异，包括人名、机构名、简称、地名、文件名。

| 已提供的语境 | 判断 |
| --- | --- |
| 同一事项前后写“由综合处牵头”和“由综合科牵头” | 如指同一牵头机构，提出具体疑点，核实机构名称 |
| 综合处负责统筹，综合科负责某下属单位具体事务 | 可能是不同机构；无相同指代证据不报 |
| 首次给出全称和简称，后文使用该简称 | 保留已明确的简称关系 |
| 一个名称出现多次，另一写法只出现一次 | 次数不能决定哪个正确，仍需指代依据 |

只给 pending，至少引用能说明差异的实际位置，不猜替换答案。相似、少见或不熟悉不是错误依据。名称索引并非权威词典，也不能证明已收齐所有名称。局部语境不足以确认同一对象时，不编造关联。
