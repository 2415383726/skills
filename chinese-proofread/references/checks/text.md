# 文字与用字判据

| 编号 | 成立条件 | 不能据此报错 |
| --- | --- | --- |
| T-TYPO | 词义及语境足以确定的形近、音近字或固定词误写 | 少见、不熟悉、另一写法更常用 |
| T-EXTRA | 确认重复录入或多出的字无实义、无句法作用 | 为简洁删词、仅凭一种切词 |
| T-MISSING | 原句存在具体缺损，且上下文能确定唯一补法 | 助词可以省略、只有补后更顺、存在多种合理补法 |
| W-DO | 做／作的词义及搭配在本句可确定 | 脱离语境统一做出／作出 |
| W-DE | 的／地／得与本句修饰对象、补语关系不符 | 把可省略的地视为漏字 |

## 成对判断示例

| 原文 | 处理与依据 |
| --- | --- |
| 请尽快部暑工作。 | 部暑 → 部署；此处表示安排工作 |
| 务必遵守工作纪律。 | 保留，词义和写法成立 |
| 请汇报工作进度度。 | 进度度 → 进度；末字重复录入 |
| 我们的工作、工作的重点 | 保留；实义与修饰关系成立，不为简洁删“的” |
| 各单位报送材料／各单位报送的材料 | 分别可能是主谓句、名词短语；不能仅因没有“的”报漏字 |
| 他高兴的说：“完成了。” | 高兴的说 → 高兴地说；修饰动作“说” |
| 任务完成地很好。 | 完成地 → 完成得；引出完成的程度 |
| 认真的学习态度 | 保留；修饰名词短语“学习态度” |
| 认真学习／认真地学习 | 均保留；“地”可省略 |
| 做为牵头单位／作好准备工作 | 分别改为作为／做好 |
| 做工作、做准备、作报告、作出决定 | 均保留 |

“制定／制订”“其他／其它”“作出／做出”等须在当前语境判断，不能全局替换。人名、机构名、地名、文件名不能因为类似常用词就改成常用词。

## 引文、标题和口语压缩的边界

先按材料语境判断，不套用普通完整书面句的长度和停顿。成立解释应自然且符合已给上下文，不靠任意补字解释原句。

- “要使用人之风真正纯洁起来”可按“要＋使＋用人之风＋真正纯洁起来”理解，不能先把“使用”固定成一个词再补“选人”。
- “面面俱到说”“官照当照升”“招进女婿气走儿”：仅凭短语不能证明必须补“地”或标点；先确认语境与结构。
- “面对矛盾总是躲着行”：行可表示行走，仅因“躲着走”熟悉不足以判错。
- “接触外界面较窄”：须考虑“接触外界的面较窄”的解析，不因把“界面”当技术名词就删去实义文字。

这些是防止误判的边界示例，不是无条件保留词表。换了上下文仍须重新判断。明显错字不因为材料是引文就自动豁免。
