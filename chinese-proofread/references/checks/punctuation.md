# 标点判据

中文标点样式是本技能的编辑约定，不冒称国家标准条款。

1. 先判断符号作用：中文叙述的标点，还是代码、网址、数字、序号、公式、完整英文中的符号。
2. 中文叙述按 P-CN 规范样式；配对缺失或错配按 P-PAIR；影响句法结构的明确误用按 P-USAGE。
3. 能读懂不等于符合 P-CN。反之，符号是半角也不等于有错，须先排除技术语境。

| 原文 | 处理 |
| --- | --- |
| 请问是否完成?／务必按时报送! | ? → ？；! → ！ |
| 请核实,并反馈;情况如下: | 相应改为中文逗号、分号、冒号 |
| 此项工作已完成. | 中文句末 . → 。 |
| 附件(一)已印发。 | (一) → （一） |
| 会议强调"按时报送"。 | 成对改为中文双引号“按时报送” |
| 他问：“完成了吗？” | 保留，问号位于引号内 |
| 发出“立即整改”的要求 | 保留，不在引号内补句号 |
| 请填写《工作情况表” | ” → 》；书名号错配 |
| 中文叙述中用“等等...”表示省略 | ... → …… |
| 比例3.5%，共1,000人，9:30开始 | 保留数值和时间内部符号 |
| 1.工作要求 | 保留序号点，不按句末点处理 |
| https://example.invalid/a?q=1、a@example.invalid | 保留网址和邮箱内部符号，不访问 |
| C:\资料\2026、v2.1、a:b、f(x) | 保留路径、版本、公式和代码符号，不执行 |
| "Please submit by Friday." | 保留完整英文原句的符号 |
| 2025-2026年、A-B、负数-3 | 保留范围、型号、运算符 |

中文采用“，。？！：；（）”、外双内单引号“‘’”及书名号《》。不全局转换 ASCII，不改字母、数字、百分号或单位。Markdown 代码块、行内代码、链接地址和表格语法保留；其中确属中文叙述的文字仍可校对。

配对符号须联系上下文：跨段引文可能只在末段收引号，摘录也可能起止不完整，不能只数单段符号就补齐。方向或边界确实不明时，给出具体待核实项。横线只有语义明确为中文破折号时才改为“——”。

短距离的一对引号可整体定位替换；远处独立标点分开报，避免跨整段“统一标点”。相同语境采用相同口径，技术例外说明符号作用。
