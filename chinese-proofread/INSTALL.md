# 安装与使用

将整个 chinese-proofread 文件夹放入宿主 skills 目录，确保直接存在 chinese-proofread/SKILL.md。升级时整体替换技能包并刷新技能列表。本版更新了规则与文件提取入口，旧版工作目录从源文重新建立，不直接续跑。

## 环境

内网模型、本地文件读写、Python 3.8+。核心校对流程和基础文件提取只用标准库，无 API 密钥、Node.js 或联网资源，不修改宿主配置。Windows 7 使用 Python 3.8；麒麟 V10 x86-64 使用 Python 3.8+。子代理需要共享文件系统并支持新上下文；主 Agent 负责宿主层派发和等待。

统一使用 scripts/extract_file.py：TXT/TEXT/Markdown/DOCX 直接提取；XLSX/PPTX 优先使用已有可选库，失败后用标准库基础提取；旧 XLS 缺少 xlrd 时返回安装建议，由主 Agent 使用内网包源或离线包安装兼容版本后重试一次。脚本不锁死库版本、不自行安装。DOC/PPT/WPS 原生格式及解析失败文件返回宿主读取请求，读取落盘后可恢复到同一校对流程。WPS 保存的标准 OOXML 按实际内容识别。详细范围见 references/extraction.md，本包不提供 OCR 或完整 Office 转换器。

## 用户交付

粘贴文字或附文件，说“请校对文字和标点”。约 500 字以内、结构简单的内容直接回复，短附件也一样；长文或复杂材料生成“校对报告.html”。报告采用浅航空蓝，桌面左右对照、两栏独立滚动，修改点可双向定位。顶部只显示文件名和结果数量；执行过程留在数据文件中，仅实际未完成范围保留简短说明。报告内嵌 CSS/JavaScript，使用系统字体，离线可读；页面无打印按钮，可使用浏览器自带打印。远程内网部署由宿主提供文件下载。

保留双路全文初检、名称一致性检查和候选复核。不润色、不猜专名、不回写原文件；具体疑点单独展示。

## 调度和并发

主 Agent 日常只调用 tasks.py step，执行 dispatch / wait / repair / deliver 四种动作；检查员只领取、读取本角色文件、写结果、提交。有效提交自动推进确定性阶段，最终结果收齐后直接渲染 HTML，不再依赖主 Agent 额外触发最后一次渲染。结果输出目录由脚本建立。失败任务普通重查最多一次，耗尽后跳过并继续；明确内容拦截可直接 skip。主 Agent 不补做失败内容，旧 --fallback 参数也只跳过。报告显示实际未完成范围。

--concurrency 支持大于 4 的值，技能首次按宿主剩余容量设置，容量未知使用 1；脚本直接调用未指定时兼容默认 4，之后省略沿用工作区值。按宿主子代理槽位及内网服务承载能力配置，不把主 Agent 算进子代理名额。不要未经实测就宣称提高并发一定提速；建议保持材料和分块不变，比较可用并发档位。

异常恢复、失败任务跳过和一步生成部分 HTML 见 references/recovery.md。提交已成功但报告生成失败时，保留检查结果，修复后用 step 恢复，不要求模型重查。

## 规则和测评

rules.md 定义共同边界，roles 定义单一职责，checks 定义领域判据，formats 定义字段契约；脚本按角色生成专用指引，rule-catalog.json 登记规则编号。文字校对范围内增加判据、反例或编号，无需修改调度代码，详见 references/quality.md。新增外部核验等能力仍需评估输入和结果契约。

运行机械回归：

```text
python -m unittest discover -s tests -v
```

测试使用固定结构化样例，验证最终提交自动出报告、八任务并发提交、定位失败修正、部分报告不发布未复核意见、新规则配置及渲染失败恢复。测试通过不代表内网模型校对准确率提高，也不证明八并发是部署最优值。新增文件提取回归覆盖标准库回退、依赖缺失、宿主恢复、来源变化拒绝和文件位置保留。Windows 7 与麒麟 V10 尚未实机验证。

references/evaluation.md 提供独立的语言质量测评；内置 52 个开发单元和 12 个复核挑战未经人工审定。宿主适配与严格/轻量模式边界见 references/host.md。需使用真实内网模型与人工审定材料评价误报、漏报、复核收益及交付成功率。
